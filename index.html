CIIFR_GEO · A / B / Consolidated

Two independent comparison bases, checked-proposal consolidation and a continuous geometry overlay.

Open Geometry Workbench →

  1. In A, click Load bundled S1 sample pair, or choose your supported SOURCE/TARGET XML.
  2. Add A anchors and run. Start with 3790 → 3790, 3830 → 3830 and 3840 → 3840 for a numerical rigid fit; or 5210 → 5210 and 5229 → 5229 for the competing-anchor experiment.
  3. Open B, enter your other interpretation, for example 5210 → 5229, and run. B initially reuses A inputs; later input changes stay independent.
  4. Check/edit the desired proposals in each table. Open C and Consolidate checked A/B pairs. Exact duplicates merge; conflict radios show the proposed combination and allow manual overrides.
  5. Try the orange/blue 3D overlay and split views, labelled paired-node selection, X/Y/Z vertical axis, and fullscreen correspondence popup. The default axis is Z.

The Δ columns describe the active overlay. Other-pair scores compare separate trial fits while excluding the tested conflict group. The retained-orientation mode is a diagnostic; rigid mode preserves native Method C rank/custody checks. TARGET reuse and partial-search limits stay visible.

The bundled F05/R4 XMLs represent the same public S1 model. They test cross-profile geometry and UI behaviour, not independent-model physical qualification. Uploaded files stay in the browser. No Writer/Apply or property transfer.
